==================================================
              對帳單工具 v1 使用說明
==================================================

━━ 第一次使用：只要做這 3 步（約 5 分鐘）━━

步驟 1️⃣：安裝環境
  雙擊「安裝環境.bat」→ 會自動安裝兩個必要軟體
  ・PowerShell 7（跑腳本需要）
  ・Access Database Engine 2016 32-bit（讀取資料庫需要）
  ⚠ 安裝時會跳出「使用者帳戶控制」，請按「是」

步驟 2️⃣：放入資料庫
  把你的「CUB.MDB」複製到這個資料夾
  （跟「對帳單.bat」放在同一個目錄）

步驟 3️⃣：開始使用
  雙擊「對帳單.bat」→ 選單出現就完成了！
  ✅ 選項 1：執行異常偵測
  ✅ 選項 2：依百分比篩選
  ✅ 選項 3：重選 CUB.MDB
  ✅ 選項 4：結束

━━ 常見問題 FAQ ━━

Q1：出現「Windows 已保護您的電腦」？
A：這是 Windows SmartScreen 的保護機制。
   請點「其他資訊」→「仍要執行」即可。

Q2：出現「找不到 PowerShell 7」？
A：重跑「安裝環境.bat」，或手動至 GitHub 下載：
   https://github.com/PowerShell/PowerShell/releases

Q3：出現「偵測不到 Access Database Engine」？
A：重跑「安裝環境.bat」，或手動下載 32-bit 版本：
   https://www.microsoft.com/en-us/download/details.aspx?id=54920
   注意：必須是 32 位元（AccessDatabaseEngine.exe，不是 _X64）

Q4：密碼錯誤怎麼辦？
A：預設密碼是 thifincub。若你的 CUB.MDB 密碼不同，
   在選單中選「5. 輸入密碼」來設定。

Q5：產出的 CSV 在哪裡？
A：在工具資料夾內，檔名為「CUB_異常社員_對帳單排序_日期.csv」，
   可以直接用 Excel 開啟。

Q6：可以放在桌面嗎？
A：可以，但路徑不要有全形空格或特殊符號。

━━ 檔案清單說明 ━━
